# 会话命名工具

`extensions/session-name` 注册常规工具 `set_session_name({name:"任务摘要"})`，让模型修改**当前 Pi 会话**的显示名称。与原生会话命名使用同一 API，名称用于会话选择器和恢复列表；持久会话由 Pi 保存，无须直接编辑 JSONL。

## 使用

安装本包后重启 Pi 或执行 `/reload`。工具默认直接暴露给模型，不需要 MCP 服务、Skill、codemode 或每轮隐藏提示。工具描述引导模型在开始用户任务前设置名称、主题明显变化时更新；这不是强制拦截器。

```json
{"name":"修复登录超时"}
```

名称建议 6–20 个汉字，最多 80 个 Unicode 字符，不能空白或含控制字符。调用返回 `ok`、`sessionId`、`name` 和 `changed`；相同名称不重复写入。

## 边界

- 通过当前扩展运行时的 `pi.setSessionName()` / `pi.getSessionName()` 修改并核验，只接受名称，不接受其他会话 ID 或文件路径。
- 仅负责当前 Pi 会话的显示名称，不修改终端窗口标题。
- 子 agent 若加载此扩展，只修改其自身会话；不捕获主会话实例或使用跨会话全局状态。
- 不修改会话 ID、JSONL 文件名、其他会话或全局配置。不含密钥、隐私等敏感信息；失败时不声称成功。
- 内存会话只在当前进程内生效；是否持久化由 Pi 当前会话的存储模式决定。
